# Simple To-Do App 

A simple web application for managing tasks, built with Node.js, Express, and a local SQLite database.

## Technologies Used
- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Node.js, Express.js
- **Database:** SQLite3


## Features
- View all current tasks
- Add new tasks to the list
- Delete completed or unwanted tasks
- Persistent storage: Tasks are saved in a local SQLite database (data remains even after restarting the server)

## Installation and Setup

Follow these steps to get the project running locally:

1. **Clone the repository:**
- git clone https://github.com/Niksi24/ToDo_app.git
- cd ToDo_app
2. **Install dependencies and packages**
- npm install
- npm install express
- npm install sanitize-html better-sqlite3
4. **Start the server**
   npm run dev or node server.js
